# Mobile AI Studio V3.0 — Phone Command + PC Host Foundation

## Product contract

The phone is the primary interface. The PC hosts local models, Quinn, validation and future agent services; it is not a user-facing desktop control panel. The app remains local-first and usable offline. GPT remains accessible through the existing ChatGPT app until a separately approved provider connection exists.

## Delivered in this branch

- V3.0 command panel inside the existing Command Center.
- HTTPS-origin validation for a future PC host. Plain HTTP, loopback, credentials, URL paths, query strings and fragments are rejected.
- Expiring five-minute pairing-request export. The request is explicitly unsigned and does not pair or authenticate a device.
- Read-only capability request list: health, telemetry and package preview.
- Phone-first custom agent designer with Music, Media and Racing floors, Director → Manager → Independent Validator reporting fields, and fixed read-only permissions. Custom roles remain drafts outside the canonical fleet until reviewed.\n- Manual Agent Factory package handoff export with strict non-executable safety flags.
- Receiving-side requirements recorded in the envelope: hash recomputation, schema validation, independent validation, Owner approval, no auto-install, no auto-activation.
- PC host protocol contract, pairing schema and test coverage.
- Service-worker cache version and offline asset list updated.

## V3.0 acceptance criteria

- Phone remains usable without network access.
- No automatic outbound request is made by the new module.
- Only HTTPS host origins are accepted for future pairing.
- Exported packages are blueprint-only and non-executable.
- No import operation activates an agent.
- Existing project, agent directory, command center, Galaxy and Agent Factory modules remain intact.
- Tests cover host URL rejection, pairing request shape, expiry, capability scope and package safety gates.

## PC-side follow-on
