# V2.1 Command Station Systems and Visual Polish

## Scope
This draft adds a phone-first visual refinement layer and local planning utilities without changing the protected V1 foundation or enabling runtime execution.

## Visual direction
- Deep navy/charcoal surfaces with restrained blue-violet ambient gradients.
- Layered cards with soft elevation shadows, inset highlights, clear borders and mobile-first spacing.
- Focus-visible states and reduced-motion support.
- No heavy animation or desktop-only layout assumptions.

## Phone-local systems
1. Agent Memory Vault: explicit categories and local-only records. No silent injection into agent prompts or sharing.
2. Collaboration Desk: structured handoff drafts; every record remains DRAFT_NOT_SENT and dispatchAuthorized=false.
3. Studio Audit Ledger: local hash-linked event history for accidental-edit detection. It is not tamper-proof, authenticated, or a secure audit service.
4. Studio Watchdog: reports only phone-observable readiness gaps. It cannot inspect the PC, Quinn, Ollama, or live runtime.
5. Provider readiness: GPT app handoff remains selected by default; Quinn/Ollama stays NOT_CONFIGURED until a later secure pairing implementation.

## Safety boundaries
- No model calls, host network calls, execution, dispatch, install, activation, publish, deployment, or external writes.
- Local browser storage is not encrypted storage and may be cleared by the browser or device.
- Audit hash chaining detects some changes but does not authenticate the event author or prevent whole-store replacement.
- Owner approval remains mandatory for consequential lifecycle changes.

## Export/validator contract
The phone exporter and desktop validator use the same mobile-ai-studio-agent-package-export/1 envelope and offline transfer flags. Automated source-contract tests guard these literals. The validator result remains VALIDATED_UNTRUSTED_PROPOSAL, not a trust or identity certification.

## Release gates still open
- Full real-roster export fixtures across Music, Media, and Racing.
- Independent code/security review.
- Physical Android browser/PWA test for download/share, safe-area layout, keyboard behavior and storage persistence.
- Windows 11 CLI smoke test using an actual phone-exported package.
- No merge, pairing, host connection, install, or activation is performed by this PR.
