# V2.0 — Phone-side agent package export

## What was added

The Agent Factory now offers **Download verified agent package (.json)** beside its existing copy action.

Before exporting, the phone:
1. Recomputes the package's canonical SHA-256 integrity fingerprint.
2. Stops if the package no longer matches its recorded fingerprint.
3. Creates a JSON export envelope containing the original blueprint package and any review records for that package.
4. Labels the handoff as OFFLINE_FILE_EXPORT and MANUAL_PC_IMPORT_REQUIRED.
5. Downloads a named JSON file to the phone's normal downloads location.

## Phone-to-PC workflow (interim)

1. Build the agent blueprint in the phone's Agent Factory.
2. Complete the separate review workflow when evidence is available.
3. Select the package and choose Download verified agent package.
4. Transfer the downloaded JSON to the desktop using the user's chosen file-transfer method.
5. Keep it as an untrusted proposal until a future desktop importer verifies the envelope and package integrity, validates the canonical role and permissions, and records the Owner's approval.

## Safety boundaries

- Downloading is not installing, activating, dispatching or executing.
- The file contains a blueprint and review records, not credentials or private keys.
- The review record remains a user-entered evidence declaration; this export does not authenticate reviewers or fetch evidence.
- A SHA-256 integrity fingerprint detects accidental or post-build modification; it is not a digital signature and does not authenticate the author or transfer channel.
- The desktop has no importer in this milestone. Manual PC import is not yet supported by a trusted tool.
- No live PC connection, Quinn/Ollama integration, shell access, filesystem write service, agent runtime or remote execution is added.

## Acceptance checks

- The selected package is required.
- The integrity fingerprint is recomputed before a file is generated.
- Tampered packages are blocked from export.
- The export envelope explicitly marks automatic installation and execution as false.
- Existing local package and review records are not modified by export.
- Service-worker cache version is advanced so installed phones fetch the updated Agent Factory module.
- GitHub Actions syntax, regression and offline-cache checks must pass before review.
