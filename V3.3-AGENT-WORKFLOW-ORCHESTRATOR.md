# V3.3 — Agent Workflow Orchestrator

## Purpose
Connects the existing phone-side Prompt-to-Agent, Tool Registry & Dependency Planner, and Independent Validation Engine into one prompt-driven workflow.

## One-prompt pipeline
1. Generate an agent blueprint using the existing deterministic Prompt-to-Agent classifier.
2. Generate a tool and dependency proposal using the existing local capability registry.
3. Generate a six-category validation evidence pack.
4. Track progress through independent validation and Owner readiness decision.
5. Export a combined JSON workflow package for review and later host handoff.

The orchestrator saves all three underlying artifacts in their existing local storage formats, plus a workflow record that links their IDs. Saved workflows can be reopened and their status recalculated from the linked evidence pack.

## Safety and trust boundaries
- Phone-local planning only. No external tool calls, package installs, Quinn/Ollama connection, host shell, host filesystem writes, model dispatch, or agent execution.
- Test cases are generated but never executed by this orchestrator.
- Validation evidence remains manually entered; reviewer identities and evidence are not authenticated or independently verified.
- Owner readiness approval is a local record, not authorization to activate, install, publish, deploy, or connect a host.
- Activation remains explicitly disabled.
- PR #7 cryptographic pairing primitives remain draft/review-only and untouched.

## Validation
Dedicated Node tests cover prompt limits, pipeline artifact creation, persisted linking, safe initial state, explicit disabled activation, status mapping, and phone asset wiring.
